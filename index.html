Proposed API contract

POST /api/v1/readings
Authorization: Bearer <device-token>
Content-Type: application/json

{
  "deviceId": "SIM-01",
  "heightCm": 18,
  "measuredAt": "2026-11-12T16:00:00Z",
  "sequence": 102
}

The server maps each device to a patient, room, and bed. Sensors do not send patient names. The server authenticates devices, validates readings and sequence numbers, records receipt times, and prevents duplicate messages.

Before real use: configure the server and authentication, calibrate sensors, test disconnections and stale readings, and clinically validate the threshold. This Wi-Fi path is a documented integration plan only; this prototype has no live API endpoint. The USB option above runs locally after manual connection.
